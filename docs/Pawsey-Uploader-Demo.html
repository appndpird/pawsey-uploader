One-time setup

Connect to Pawsey

Do this once

  • Paste your Access key ID and Secret access key from Pawsey
  • Endpoint defaults to projects.pawsey.org.au — leave it
  • Click Save & apply to rclone, then Test connection
  • Set your usual default bucket & source folder to save typing

Keys disabled? A 403 UserSuspended means Pawsey turned your keys off — email help@pawsey.org.au. No app setting can fix that.

Rule of thumb: start with Copy. Only reach for Mirror or Two-way sync when you specifically need deletions to propagate — and keep the recycle bin on when you do.

Copy · one-way, additive

Scenario 1 — First upload & archiving

When to use

You're sending data to Pawsey for the first time, or topping up an existing archive with new files. Copy only ever adds and updates — it never removes anything on Pawsey, so it's impossible to lose data with it.

Before you click Start

  • Source folder is correct
  • The blue "Files will be placed under…" line points where you expect
  • You've written a note (required)

Renamed a file? Copy can't tell — it uploads the new name and leaves the old one too. Use Mirror or Two-way for renames.

Mirror · one-way, exact

Scenario 2 — Make Pawsey match exactly

When to use

You want Pawsey to become an exact replica of your local folder — including removing files on Pawsey that you've deleted locally. Good for publishing a cleaned-up, final version of a dataset.

Before you click Start

  • Recycle bin ticked — deleted files move to _recycle_bin/, not gone
  • Leave the delete safety cap on
  • Detect renamed/moved files on → renames become server-side moves, no re-upload

Mirror deletes anything on Pawsey that isn't in your source. The app shows a list of what will be removed and makes you confirm.

Two-way sync · OneDrive-style

Scenario 3 — Keep both sides in sync

When to use

You add, edit or delete files on either side — your laptop, the office PC, or Pawsey — and want every change to flow both ways automatically.

How it works

  • The first run builds a baseline (local wins any clash); after that both sides are equal partners
  • Always use the same folder + same Pawsey path for a project
  • Tick Auto-sync every N min to keep it running OneDrive-style
  • Set conflict resolution for files changed on both sides
Resume previous…

Scenario 4 — It got interrupted

What to do

  • Reopen the app after a crash, reboot, or dropped link
  • Transfer tab → choose Resume previous…
  • Pick the transfer from the list (last 50 are remembered)
  • Click Start — rclone skips files already uploaded

It often resumes itself

  • Auto-restart on a network blip — up to 10 tries with backoff
  • Stops cleanly on real errors (bad keys, missing bucket)
  • Keeps your PC awake while a transfer runs
  • A heartbeat file lets you check it's alive from another session

Sync options

Your safety controls

If files differ

Keep newer, keep both, or let local / Pawsey win when the same file changed on both sides.

Recycle bin

Deleted & overwritten files move to _recycle_bin/ in the bucket — a built-in version history.

Delete safety cap

Abort a two-way sync that would delete more than N% of files. Guards against accidental wipes.

Require matching names

Blocks a sync if the source folder name ≠ destination name. Stops the wrong project syncing into the wrong place.

Detect renamed files

Renames become server-side moves on Pawsey — no slow re-upload of huge folders.

Verify with checksums

Compares by MD5 hash instead of size + time. Slower, but catches silent corruption.

Buckets & Storage

Audit trail

Nothing happens without a note

Why it matters

Every transfer, delete, rename and upload is written to a permanent log with the note you wrote, the source, the destination, and the final status.

  • The note is mandatory — no note, no transfer
  • Answers "who put this here, and why?" months later
  • Open log folder jumps straight to the raw files

Keep these in mind

Seven golden rules

  • Copy is the safe default — it never deletes.
  • Read the blue "Files will be placed under…" line every time.
  • Mirror and Two-way can delete — keep the recycle bin on.
  • Always write a real note — it's your future audit trail.
  • For two-way sync, reuse the same folder & path per project.
  • Renaming a big folder? Use Storage → Rename / Move, not a re-upload.
  • Empty the recycle bin now and then — it counts toward your quota.

If something looks wrong

Troubleshooting

rclone not found

Point Settings → Path to rclone at the bundled rclone.exe, or install rclone and restart.

403 UserSuspended

Your Pawsey keys are disabled. Email help@pawsey.org.au — no setting fixes this.

Transfer stopped halfway

Reopen → Resume previous… → pick it → Start. Already-uploaded files are skipped.

Must run --resync

A two-way baseline was lost. Just run the pair again — the app rebuilds it without losing remote changes.
